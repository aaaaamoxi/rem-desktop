# 发布说明（给别人用的时候要说的）

## 体积

| 东西 | 大小 |
|---|---|
| NSIS 安装包 | 约 117 MB |
| 安装后占盘 | 约 360 MB |
| 网页版本 | 不到 2 MB（两个立绘 + 一堆代码） |

为什么这么大：Electron 自带 Chromium 内核。里面绝大部分是浏览器，
应用本身只有 750 KB。

## 会被拦的地方

**Windows SmartScreen** 会拦未签名的程序：
双击安装包 → 蓝色窗口写"Windows 已保护你的电脑" → 点「更多信息」→ 「仍要运行」。

**杀毒软件可能误报**：未签名的 Electron 程序常被误报（尤其是"捆绑"类提示）。
程序本身干净 —— 没有联网、没有后台服务、不写注册表（除了开机自启那个开关）。

## 它会真的动你的文件

**这一点必须说清楚。**

桌面版"吃掉"一个图标 = 把那个文件**移走**，进桌面上一个叫「吃掉的食物」的文件夹。
不是复制，是移动。

- 想全部要回来：右键她 →「吃掉的食物」→「全部吐回」
- 文件会放回**原来在的地方**，名字也还原
- 那个位置已经有同名文件了，会自动改成 `xxx (2)`，**不会覆盖你原来的**
- 万一原位置写不进去（比如「所有用户桌面」那种系统目录），会放到你自己的桌面上，并在提示里告诉你

**建议第一次用先建两个没用的快捷方式试试。**

## 怎么彻底删干净

1. 「设置 → 应用 → 雷姆桌宠」→ 卸载
2. 删掉 `%APPDATA%\desktop-pet\`（存档和日志）
3. 删掉桌面上的「吃掉的食物」文件夹（如果还有东西）
4. 如果开了开机自启：删掉 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\` 里的快捷方式

## 已知问题

| 现象 | 原因和解决 |
|---|---|
| 双击没反应，进程还在 | 环境变量 `ELECTRON_RUN_AS_NODE` 被设了（某些开发工具会带进来）。程序会自动清掉重启；如果还是不行，看安装目录里的 `启动日志.log` |
| 点不到桌面图标 | 只有她身上那一片接管鼠标，其余穿透。托盘里隐藏再显示一次 |
| 透明窗口黑底 / 闪屏 | 少数显卡驱动的问题。设环境变量 `DESKTOP_PET_NO_GPU=1` 再启动 |
| 杀软报警 | 未签名程序常见误报，见上文 |
| 不知道她吃了什么 | 右键她 →「吃货日志」，或托盘 →「打开吃货日志」 |

## 数据在哪

| 东西 | 位置 |
|---|---|
| 存档 | `%APPDATA%\desktop-pet\pet-state.json` |
| 吃货日志 | `%APPDATA%\desktop-pet\吃货日志.txt` |
| 她吃掉的 | 桌面上的「吃掉的食物」文件夹 |

全部在你自己的电脑上，**不联网、不上传**。
