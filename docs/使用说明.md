# 雷姆桌宠 · 桌面版 使用说明

她叫拉姆，也叫雷姆。一只住在你 **Windows 桌面**上的小家伙。

透明窗口浮在真实桌面上：她走来走去、发呆、眨眼，饿了会爬到你桌面上的图标旁边
把它们**真的移走**，闲了跟你说句话。深夜她会催你睡觉。
你要是太久不开电脑，她会饿到长眠，临走前在桌上留一封遗书。

> ⚠️ **先看这条**
> 桌面版会**真的移动你的桌面文件** —— "吃掉"就是文件被移走，不是复制。
> 这是它和网页版唯一的区别，也是这个应用最"吓人"的一点。
> 第一次用建议先建两个没用的快捷方式试试，
> 右键她 →「吃掉的食物」→「全部吐回」能原样还回来。

## 一、怎么装、怎么开

### 直接用安装包（推荐给不想折腾的人）

`release/` 里有现成的安装包：

```
release/雷姆桌宠-0.4.0-安装包.exe
```

双击 → 选安装目录 → 完成。会建桌面快捷方式和开始菜单项。
要卸载走「设置 → 应用 → 雷姆桌宠」。

### 自己跑（想改代码的人）

```bash
npm install
npm start
```

启动后终端第一行是自检信息：

```
[pet] electron 45.1.0 | packaged false | userData …\desktop-pet-dev | debug true
```

她浮在真实桌面上，**左下角自带调试面板**（改参数不用重新打包）。
改完参数 → 托盘 →「重新加载」，立刻生效。

## 二、她自己做这些

| 动作 | 效果 |
|---|---|
| 什么都不做 | 自己走路、发呆、眨眼、抖呆毛 |
| 饿得厉害了 | 自己爬过去找图标吃（饥饿值超过 72） |
| 等到深夜 23:30 以后 | 提醒你睡觉 |
| 你太久不来（饿满 100 且离线超过 96 小时） | 她长眠，桌面多一个 `遗书.txt` |

**她右上角有一根竖着的小条**，是饥饿值（绿色→黄色→红色，越高越饿），鼠标停上去能看到具体数值。
桌面版没有假任务栏，就靠它告诉你她饿不饿。

## 三、你能对她做的

| 动作 | 效果 |
|---|---|
| 单击她 | 冒出一句话 |
| 快速连点 4 下（300ms 内） | 她会抖屏幕闹脾气 |
| 按住拖拽 | 拖起来跟着你的手倾倒，松手掉回地面弹一下 |
| **把桌面的文件拖到她身上** | 主动投喂，她张嘴吃掉（真文件被移走） |
| 右键她 | 菜单：说话 / 喂她 / 吃掉的食物 / 换个形象 / 吃货日志 / 她还记得什么 / 重置 |
| 什么都不做 | 她就一直自己待着 |

## 四、托盘菜单

托盘右下角她的小头像，右键：

| 菜单项 | 干什么 |
|---|---|
| 显示 / 隐藏 | 让她消失一会儿 / 再叫出来 |
| 打开吃掉的食物 | 直接打开那个文件夹（她吃掉的都在这儿） |
| 开机自动出现 | 写进你的启动文件夹，开机就有她（不需要管理员权限） |
| 打开数据文件夹 | 存档和日志在这儿 |
| 打开吃货日志 | 用记事本打开全文 |
| 重新加载 | 改完代码立刻生效 |
| 开发者工具 | 调试用 |
| 调试面板 显示/隐藏 | 折叠起那排调试按钮 |
| 退出 | **唯一的退出入口** |

> **没有托盘就等于没有退出入口**，所以别在任务管理器里强杀。

## 五、她把我的文件吃了，怎么要回来

右键她 → **吃掉的食物** → 「吐回来」。

- 文件会放回它**原来在的地方**，名字也还原
- 那个位置已经有同名文件了，会自动改名叫 `xxx (2)`，**不会覆盖掉你原来的**，弹窗里会告诉你改成了什么
- 万一原位置写不进去（比如「所有用户桌面」那种系统目录，普通用户没权限写），
  文件会放到**你自己的桌面**上，并在提示里告诉你 ——
  Windows 桌面本来就是"用户桌面 + 公共桌面"两个目录合并显示的，看起来一样

她吃的文件都躺在桌面上一个叫 **「吃掉的食物」** 的文件夹里，托盘里能直接打开。

## 六、吃货日志

她吃掉什么、什么时候吃的、那是哪个应用，全都记着：

```
2026-10-31 11:53:06 | 吃掉 | 微信.lnk | 应用：Weixin | 来自 C:\Users\X280\Desktop
2026-10-31 13:52:27 | 吐回 | 微信.lnk | 放回 C:\Users\X280\Desktop
2026-10-31 13:52:30 | 还不了 | 照片.jpg | EPERM | 原位置写不进去
```

四种动作：`吃掉`、`吐回`、`吃不下`、`还不了`（失败会带真实原因）。

「应用」那一栏读的是快捷方式真正指向的程序
（`.lnk` 用 Electron 的 `shell.readShortcutLink` 解析），比如 `微信.lnk` → `Weixin`。
普通文件就显示文件名。

三个地方能看到：

- 右键她 → **吃货日志**（应用里看，最近 60 条）
- 右键她 → **她还记得什么**（同一份日志的最近 12 条）
- 托盘 → **打开吃货日志**（记事本打开全文，在 `%APPDATA%\desktop-pet\吃货日志.txt`）

## 七、常见问题

**Q：点不到桌面图标了？**
只有她身上那一片会接管鼠标，其余地方应该穿透过去。
如果整块桌面都点不到，是穿透失效了 —— 托盘里隐藏再显示一次。

**Q：透明窗口黑底 / 闪屏？**
少数显卡驱动的问题。设环境变量 `DESKTOP_PET_NO_GPU=1` 再启动（关硬件加速）。

**Q：她站的位置和图标差一点？**
桌面图标间距由 Windows 的缩放比例决定，我们用的是 100% 缩放的近似值（75×96）。
差个十几像素是正常的。

**Q：点了没反应，什么都没弹出来？**
打包版 exe 正在跑时会抢单实例锁。开发版已用独立 userData（`desktop-pet-dev`），
两个能同时跑。

**Q：怎么让她彻底消失？**
托盘 →「退出」。彻底删干净的话：
「设置 → 应用」里卸载，再删掉这两个遗留位置：

- `%APPDATA%\desktop-pet\`（存档和日志）
- 桌面上的 `吃掉的食物\` 文件夹（她吃掉的那些）

## 八、想改点什么

改完**托盘 →「重新加载」**就生效，不用重新打包。

| 想改什么 | 改哪 |
|---|---|
| 饿得多快、多久算饿死、吃一个回多少 | `src/js/config.js` 的 `hunger` |
| 走路速度、深夜提醒时间 | `src/js/config.js` 的 `move` / `night` |
| 所有台词 | `src/js/config.js` 的 `lines` |
| 角色大小、嘴的位置、着地高度 | `src/js/chars.js` 的 `w/h/gap/float/mouth` |
| 眼睛补丁、闭眼弧、开心眼弧的形状 | `src/js/pet-face.js` 的 `patch/closed/happy` |
| 呼吸、走路、咀嚼的幅度 | `src/css/pet.css` 的 `breathe / walk-bob / art-chew` |

台词怎么写见 [`台词池.md`](台词池.md)。

## 附：要把这个发给别人的话

- **体积**：安装包约 120 MB，解压安装后约 360 MB
- **Windows SmartScreen** 会拦未签名的程序 —— 点「更多信息」→「仍要运行」
- **杀毒软件可能误报**：未签名的 Electron 程序常这样，不是真的有病毒
- **一定要说清楚**：它会真的移动别人的桌面文件
