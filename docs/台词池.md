# 台词池（你来写的那 20 条）

台词写得好不好，直接决定她像不像"活的"。我给的都是初稿，你按自己的语感改，改完刷新网页就生效——不用重新打包。

## 怎么改

打开 `src/js/config.js`，找到 `lines`，每一组都是一个数组，加一行加一句话：

```js
idle: [
  '你在忙什么？',
  '我今天什么也没干。',   // ← 就这样加
],
```

## 现有分组

| 分组 | 什么时候说 |
|---|---|
| `greet` | 你重新打开网页时的第一句 |
| `idle` | 闲着没事时随机说 |
| `hungry` | 饱腹度低、找不到吃的 |
| `eat` | 吃掉一个图标之后 |
| `full` | 吃太多、被拒绝时 |
| `sleep` / `wake` | 睡前 / 被吵醒 |
| `night` | 深夜提醒 |
| `disturb` | 你连点她 4 下之后 |
| `weak` / `revive` | 饿到奄奄一息 / 被救回来 |
| `held` | 被拖起来的时候 |

## 写作要约

1. **短**：一句不超过 12 个字，气泡就那么点大
2. **不解释**：不要写"我会吃掉你的图标哦～"，让她做，不要让她介绍自己
3. **少感叹号**：一个感叹号都不加也不会不热情
4. **有一点点丧**：她是那种"不太会说话但一直在"的性格，别写成客服
5. **别用"～"和 emoji**


## 一句示例（可参考的语感）

| 别这么写 | 这么写 |
|---|---|
| 主人你来啦！我好想你呀～ | 你回来了。 |
| 我饿啦，快喂我吃东西嘛！ | 那个图标看起来能吃。 |
| 呜呜呜你不要走好不好 | 你走了 3 天。 |
